# IceTaskThree_CSS
Understanding of CSS style of a webpage - Ice Task 3

ICE Task 3 – CSS Styling
About

This project demonstrates my understanding of CSS selectors and pseudo-classes.

I used the supplied HTML and created an external CSS file called style.css to style the webpage.

Files
index.html – HTML structure
style.css – CSS styling
README.md – Project information
CSS Used

The following CSS selectors were used:

Element Selector – styles elements such as body and footer.
Class Selector – styles classes such as .course-card.
ID Selector – styles the #main-header.
Grouping Selector – styles h1 and h2 together.
Descendant Selector – styles elements inside .course-card.
Pseudo-Class – uses :hover to change links and the Contact Us button.
CSS Comments – used to explain the different sections of the CSS.
Design

The webpage includes:

Background styling
A styled header
Course cards
A featured course
Styled links
Contact Us button
Hover effects
Footer
Margin and padding
External CSS

The CSS file is connected to the HTML using:

<link rel="stylesheet" href="style.css">
Conclusion

This project shows my understanding of basic CSS selectors, pseudo-classes and webpage styling.
